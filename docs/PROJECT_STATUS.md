# Состояние проекта Бузя

Последнее обновление: 2026-11-16

## 1. Языковое ядро

Основной кандидат:
- Репозиторий модели: `RWKV/RWKV7-G1l-1.5B-20261031`
- Архитектура: RWKV-7 (рекуррентная архитектура, не Transformer).
- Размер: 1.5B.
- Роль в проекте: языковое ядро Бузи.

Важно: не переносить автоматически на RWKV-7 предположения и обучающие процедуры, предназначенные для Transformer. Перед обучением изучить родную реализацию RWKV-7, формат состояния, inference и training pipeline конкретного checkpoint.

## 2. Среда запуска

Зафиксированная тестовая среда Google Colab:
- GPU: NVIDIA Tesla T4, 15 GB VRAM.
- PyTorch: 2.14.1+cu130.
- CUDA runtime: 13.0.
- Transformers: 5.23.0.
- Accelerate: 1.15.0.
- Модель успешно загружалась на `cuda:0`.

Эти версии описывают одну рабочую сессию, а не гарантированно воспроизводимую среду. Для восстановления потребуется повторная проверка совместимости и фиксация точных зависимостей.

## 3. Проверки генерации

Проверено:
- генерация с chat template и system-сообщением;
- генерация без system-сообщения;
- продолжение короткого диалога из нескольких сообщений;
- попытка переключения между образным и научным стилями.

Наблюдения:
- базовая модель способна выдавать связные, иногда неожиданные ответы;
- следование сложным инструкциям нестабильно;
- встречаются фактические ошибки и незавершённые ответы;
- модель может воспроизводить шаблонные самоописания.

Эти результаты не свидетельствуют о наличии сознания, человеческих переживаний или устойчивой личности.

## 4. Данные: OASST1

Источник: https://huggingface.co/datasets/OpenAssistant/oasst1

Был загружен train split и отфильтрован по условиям:
- `lang == "ru"`
- `deleted == False`
- `review_result == True`

Результаты:
- исходный загруженный train split: 84 437 сообщений;
- validation split: 4 401 сообщение;
- отфильтрованный русскоязычный train-срез: 6 953 сообщения;
- роли: 3 002 `prompter`, 3 951 `assistant`;
- уникальных `message_tree_id`: 723;
- извлечено root-to-leaf цепочек: 2 808;
- сформировано прямых пар user → assistant: 3 949;
- уникальных формулировок вопросов в этих парах: 1 874.

### Ранжирование

Распределение rank у assistant:
- rank 0: 1 527;
- rank 1: 1 520;
- rank 2: 540;
- rank 3: 6;
- rank отсутствует: 358.

Среди групп с несколькими ранжированными ответами:
- (0, 1): 980;
- (0, 1, 2): 533;
- (0,): 7;
- (0, 1, 2, 3): 6;
- (1,): 1.

Предварительно сформировано 1 526 пар с ответами rank 0, с 1 517 уникальными формулировками вопросов.

**Важно:** это предварительный исследовательский срез, а не готовая обучающая выборка. Нужны проверка качества, лицензии, удаление обрывов и оценка содержимого. Не считать rank абсолютной оценкой фактической правильности.

### Наблюдения по качеству

- Есть альтернативные ответы на одинаковые вопросы.
- Встречаются формальные, энциклопедические и рекламоподобные ответы.
- Некоторые факты могут быть устаревшими.
- Есть длинные сообщения и потенциальные обрывы.
- Несколько ответов могут быть разными по стилю, а не просто по качеству.

## 5. Направление характера генерации

Целевые особенности речи для экспериментов:
- теплота без приторности;
- любопытство и иногда наивность;
- естественная разговорная речь;
- уместная резкость и строгость;
- способность использовать разговорную лексику, не превращая её в постоянную грубость;
- гибкое переключение тона в зависимости от ситуации.

Это пока экспериментальные цели для тестирования, а не закреплённые свойства модели.

## 6. Постоянство и переносимость

Проект должен переживать потерю доступа к отдельному сервису или аккаунту.

План:
- код и документация — GitHub;
- веса модели — отдельные резервные копии в независимых хранилищах;
- датасеты — отдельное хранение с описанием источника и лицензии;
- внешняя память — переносимая база с экспортом и резервными копиями;
- зависимости и инструкции — фиксировать по мере стабилизации;
- для крупных файлов хранить контрольные суммы.

GitHub не заменяет резервную копию весов и данных.
