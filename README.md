# Бузя

Экспериментальный проект разговорного ИИ на базе **RWKV-7**.

Цель проекта — собрать переносимого ИИ-агента: отдельное языковое ядро, внешняя память, инструменты и собственная среда запуска. Проект не должен зависеть от одной облачной платформы.

## Текущий статус

- Основной кандидат языкового ядра: `RWKV/RWKV7-G1l-1.5B-20261031`.
- Модель загружена и запускалась в Google Colab на NVIDIA Tesla T4 (15 GB VRAM).
- Проверена генерация с chat template.
- Исследован русскоязычный срез OASST1.
- Подготовлен предварительный отбор предпочтительных ответов, но **обучение весов ещё не начиналось**.

## Архитектурный принцип

Бузя строится вокруг RWKV-7, а не подгоняет RWKV под привычный трансформерный pipeline.

Планируемые отдельные части:
1. Языковое ядро RWKV-7.
2. Внешняя краткосрочная и долговременная память.
3. Поиск и извлечение релевантной информации.
4. Инструменты и управление контекстом.
5. Тесты генерации, качества и восстановления.

## Безопасность

Не добавлять в репозиторий:
- токены, пароли, ключи API и cookies;
- личные данные и приватные переписки;
- веса модели и большие файлы датасетов;
- временные файлы Colab и кэши.

Перед публикацией новых файлов проверять их содержимое и лицензии источников данных.
